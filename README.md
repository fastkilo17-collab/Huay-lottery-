# สถิติผลฮานอย

เว็บแอปอ่านผลรางวัลจากภาพแคปหน้าจอหรือวิดีโออัดหน้าจอ (ฮานอย 27) เก็บลง Supabase และวิเคราะห์สถิติ
ทำงานในเบราว์เซอร์ทั้งหมด ไม่ใช้ API ภายนอกในการอ่านภาพ

## ไฟล์
- `index.html`, `app.js` — หน้าเว็บ
- `lotto-core.js` — ตรรกะอ่านภาพ ตรวจความถูกต้อง และสถิติ (ไม่ผูกกับ DOM)
- `templates.js` — แม่แบบตัวเลขของแอปหวย (สร้างด้วย `build-templates.js` จากภาพตัวอย่างที่รู้เฉลย)

## วิธีทำงาน
1. หาตำแหน่งตารางสีฟ้า (สิบ/หน่วย) ในภาพอัตโนมัติ (รองรับภาพที่ถูกครอป/ซูม/ย่อ) แล้วตัดช่องรางวัล แยกตัวเลขทีละหลัก เทียบกับแม่แบบ
2. ตรวจ: เลขท้าย 2 ตัวของทั้ง 27 เลข ต้องตรงกับตารางสิบ/หน่วยในภาพ
3. ผ่านแล้วบันทึกลง Supabase (`save_draw` RPC, กันซ้ำด้วยเลขงวด, RLS ต่อผู้ใช้)

## ขึ้นเว็บ (GitHub Pages)
Settings → Pages → Deploy from a branch → `main` / root

## ตั้งค่า Supabase
รันไฟล์ `supabase-open-access.sql` ใน SQL Editor ก่อนใช้งาน (เปิดให้อ่าน/เพิ่มโดยไม่ต้องล็อกอิน ลบไม่ได้)

ค่า URL และ publishable key อยู่ต้น `app.js` (ปลอดภัยให้อยู่ฝั่งเว็บ เพราะข้อมูลป้องกันด้วย RLS)

## หมายเหตุ
ผลแต่ละงวดเป็นอิสระต่อกัน สถิติย้อนหลังทำนายงวดถัดไปไม่ได้

## แท็บ "ย้อนหลังจากเว็บ"
บันทึกหน้าผลย้อนหลังของหวยแต่ละชนิดจากเบราว์เซอร์ (.html หรือ .mht) แล้วนำเข้า ระบบเก็บผลรายงวดแยกตามหวย และคำนวณสถิติแต่ละคอลัมน์ (เช่น 3 ตัวบน / 2 ตัวล่าง) เอง
